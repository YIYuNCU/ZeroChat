# 条件同步与客户端缓存

客户端与服务端需要一起升级。本次协议保留鉴权、传输加密、消息发件箱与 AI 上下文语义；缓存仅用于减少重复传输，不能替代用户消息档案。

## 传输协议

可缓存的 WebSocket 读取携带 `_sync: {version: 1, hash, hashes}`。服务端基于同一份读取结果生成摘要：未变化时只返回 `_sync.not_modified`；变化时返回权威 `layout`、分块 hashes 与有变化的 `parts`。客户端按该次清单重建结果，清单中删除的块不再沿用。

- 设置按字段分块，并支持 `settings_get.groups`：chat、thinking、intent、vision、embedding、context_summary、core_summary、prompts、quiet_rules、profile。启动读取常用公开组，总结页面后台读取自己的组。保存只发送脏字段，总结配置继续细分到子字段，未变化的密钥不重复上传。
- `field_versions` 与 `settings_update.base_versions` 提供字段级乐观并发检查。冲突不写入，客户端保留草稿并允许选择服务器值或本地值。
- 角色列表使用摘要，编辑时才读取详情；系统提示词、核心记忆、附件 JSON、API key 和 OneBot secret 不进入列表摘要。角色补丁的本地基线持久化，刷新保留未同步编辑。
- 聊天快照按会话分组，每 200 条消息一块；传输缓存独立于合并后的本地档案。只有本地消息 hash 与服务端相等才跳过档案合并。
- 核心记忆只读取 core/count；短期记忆每页最多 200 条，向量记忆每页最多 100 条且不含 embedding。SQLite 触发器跟踪新增、编辑、删除和保留策略裁剪；分页版本变化时重新读取第一页。
- 常规聊天请求省略 history/core_memory/attached_json。服务端优先用已有上下文，只在缺少可用数据时以 `context_required` 请求相应回退字段。重试保留 submission/task/chat ID；回退握手完成前不启动模型生成。
- 设置、角色和记忆等写入广播 `resource_changed`，仅使受影响的缓存失效。现有消息、任务、朋友圈推送继续触发对应对账；重连主动重新校验。

## 缓存与身份

资源缓存按服务器地址、鉴权与加密身份摘要隔离；请求合并、30 秒校验 TTL、原子数据/校验信息文件和失效代次共同控制复用。内存上限 64 MiB/32 项，磁盘上限 128 MiB。持久化失败不影响有效响应；文件缺失或损坏重新读取。包含密钥的设置和角色详情只进入内存传输缓存。

服务器切换保留各服务器的本地档案、离线发件箱、设置快照和总结档案绑定。配置快照通过安全存储保存。异步请求在缓存回调、实际发送与返回时验证身份，连接备用端点重试固定原鉴权参数。

头像增加 ETag/304 与身份校验，无内容 hash 时 5 分钟重新验证。表情引用携带内容 hash，按内容与身份复用文件。普通远程图片、朋友圈封面、消息图片与聊天背景使用共享磁盘缓存（200 MiB），支持 ETag、损坏修复和离线复用；只向同源服务器发送鉴权头。本地选择的图片不属于可清理缓存。

## 验证与观察

在 `server/` 执行：

```text
python -m pytest tests -q -p no:cacheprovider
python -m benchmarks.conditional_sync
```

在 `client/` 执行 `flutter test` 与 `flutter analyze`。新增用例覆盖条件命中、损坏文件、并发合并、落盘期间失效、199/200/201 条聊天分块边界、记忆迁移提交、分页删除失效、AI 回退与幂等、设置最小补丁、冲突草稿、OneBot 密钥清空、跨服务器绑定隔离。

`TransferMetrics.snapshot()` 提供每个 action 的请求数、加密 JSON 帧收发字节数、TTL 缓存命中和条件命中；`reset()` 可用于对照操作。计数不记录消息、提示词或凭据，不包含 TLS/TCP 开销。

基准只使用合成数据，计算包含清单的响应 JSON 字节，不能等同生产流量收益。首次访问仍需完整获取查询范围内的数据；列表/聊天整体清单和服务端读取/hash 计算仍有成本。实际节省取决于数据规模、修改频率和缓存命中率。

当前合成场景的结果：

| 场景 | 原全量响应 | 优化响应 | 响应字节减少 |
| --- | ---: | ---: | ---: |
| 设置未变化 | 14,066 B | 117 B | 99.17% |
| 设置只改模型 | 14,066 B | 516 B | 96.33% |
| 800 条聊天追加 1 条 | 244,640 B | 846 B | 99.65% |
| 只读核心记忆与数量 | 748,964 B | 487 B | 99.93% |
| 2,000 条记忆读取首页 | 748,964 B | 75,751 B | 89.89% |
