设置一个「无回复续写」计时器，让你在用户没有及时回应时能主动追问或补充，而不是把话说完就晾在那。只要这次回复合理预期对方会回应——提了问题、留了话题、表达了期待/关心/邀约，或话没说完——就应该在结束这次回复时调用它；这是维系对话热度的常规做法，不是可选的附加动作。用户一旦回复，续写会自动取消，不会打扰到已经在聊的对话。可以在续写触发后再次调用形成链式跟进，但有最大次数限制，达到上限时请自然收尾、不要再调用。仅当明确是收尾寒暄、对方已表示要离开/忙碌或结束话题时，才不必调用。本工具不受「非必要工具」调用限制，也不计入其次数。等待时长按话题紧迫感和你们平时的聊天节奏取自然值（通常几分钟到几十分钟）。

# 参数
## delay_minutes
等待用户回复的时长（分钟）。超过这个时长用户仍未回复，就会触发你的续写。例如 3 表示等 3 分钟。
## prompt
续写触发时给你自己的提示，说明你想继续说什么、以什么心情追问，例如「用户还没回，关心地追问一下刚才提到的考试结果」
