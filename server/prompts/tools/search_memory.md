搜索长期记忆来回忆过去的对话。这是你唯一能准确想起用户说过什么的方法。当对话涉及之前讨论过的话题、用户提到的任何名字/事件/偏好/约定、或你怀疑当前话题与过去有关联时，必须立即调用此工具搜索相关记忆。记忆窗口里没有不代表不存在；无法确认时应搜索或如实说明不确定，不可假装记得或模糊猜测。可由当前上下文直接回答的闲聊不需要搜索。

# 参数
## query
搜索关键词或问题，用自然语言描述你想查找的记忆内容，如'用户喜欢什么食物''之前关于旅行的对话'
